# RecipeCloud

RecipeCloud is a SwiftUI iOS app for keeping a personal recipe collection in the cloud. The app stores recipes in Firebase Realtime Database, updates the list in real time, and lets users quickly add, search, favorite, and delete recipes.

## Why This Name

`RecipeCloud` replaces the assignment-style name with a product name that describes the app clearly: recipes are saved remotely and stay available through Firebase synchronization.

## Features

- Real-time recipe list powered by Firebase Realtime Database
- Add recipes with title, cuisine, preparation time, difficulty, ingredients, and steps
- Search recipes by title or cuisine
- Mark recipes as favorites
- Filter the list to show favorites only
- Delete recipes with swipe actions
- Loading, error, and retry states
- Clean SwiftUI interface with `NavigationStack`, `List`, `Form`, sheets, toolbar actions, and searchable content

## Firebase Data Model

Recipes are stored under the `recipes` node in Firebase Realtime Database.

```json
{
  "recipes": {
    "autoGeneratedRecipeId": {
      "title": "Pasta",
      "cuisine": "Italian",
      "prepMinutes": 25,
      "difficulty": "Easy",
      "ingredients": ["Pasta", "Tomato sauce"],
      "steps": ["Boil pasta", "Mix with sauce"],
      "isFavorite": false,
      "createdAt": 1780590000
    }
  }
}
```

## Requirements

- macOS with Xcode installed

- `GoogleService-Info.plist` for the app bundle

## Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/KarinaTulegenova/Assignment8.git
   cd Assignment8
   ```

2. Open the project in Xcode:

   ```bash
   open Assignment8.xcodeproj
   ```

3. Create or open a Firebase project in the Firebase Console.

4. Add an iOS app in Firebase using the bundle identifier from Xcode:

   ```text
   kz.aitu.Assignment8
   ```

5. Download `GoogleService-Info.plist` from Firebase.

6. Add `GoogleService-Info.plist` to the Xcode project target.

7. Enable Realtime Database in Firebase and create the `recipes` path.

8. Run the app from Xcode.

## Database Rules for Development

For local testing, Firebase Realtime Database can be opened temporarily:

```json
{
  "rules": {
    ".read": true,
    ".write": true
  }
}
```

For production, replace these rules with authenticated access rules.

## How It Works

`Assignment8App` configures Firebase when the app starts. `RecipeListView` creates `RecipeViewModel`, which subscribes to recipe updates through `RecipeService`. The service listens to the Firebase `recipes` node, converts snapshots into `Recipe` models, sorts them by creation time, and publishes changes back to the SwiftUI interface.

Adding, deleting, and favoriting recipes are written directly to Firebase, so the visible list updates through the real-time listener.

## Current Limitations

- Recipe detail screen is not implemented yet.
- The Xcode target name and bundle identifier still use the original assignment naming.
